# Biblioteca API

API REST de uma biblioteca desenvolvida em Java com Spring Boot.

O projeto permite cadastrar, consultar, atualizar e excluir livros, utilizando MySQL para armazenamento dos dados.

## Tecnologias

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* Maven

## Funcionalidades

* Criar livros
* Listar livros
* Buscar livro por ID
* Atualizar livros
* Excluir livros

## Como executar

Clone o repositório:

```bash
git clone https://github.com/felipe-medino/biblioteca-api.git
```

Configure o acesso ao MySQL no `application.properties` e execute o projeto pelo IntelliJ ou utilizando o Maven.

A aplicação será executada em:

```text
http://localhost:8080
```

## Objetivo

Projeto desenvolvido para praticar desenvolvimento backend com Java, Spring Boot, APIs REST e integração com banco de dados.
